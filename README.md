# Меч Разрыва — Эа (Sword of Rupture)

Мод для Minecraft 1.21.1, NeoForge 21.1.x. Этап 1: рабочий скелет.

## Запуск
```
./gradlew runClient      # тестовый клиент
./gradlew build          # jar в build/libs/
```
Выдать меч: `/give @s rupture:sword_of_rupture` (также есть во вкладке «Бой» в творческом режиме).

## Что работает
| Механика | Где в коде |
|---|---|
| Предмет: 30 урона, неразрушимый, огнестойкий | `item/SwordOfRuptureItem` |
| Зарядка на ПКМ, вращающиеся частицы, процент заряда в actionbar | `onUseTick` |
| Пассивные частицы искажения в руке | `inventoryTick` |
| Выстрел: конусный луч + удар по области, урон = maxDamage × заряд^k | `strike/RuptureStrike` |
| На высоком заряде урон в обход брони, эффектов, зачарований, щита и кадров неуязвимости | `data/rupture/damage_type/rupture_true.json` + теги `minecraft:bypasses_*` |
| Снимок блоков (состояние + NBT блок-сущностей), удаление без дропа | `restore/RestoreJob.carve` |
| Рамки, картины, стойки для брони тоже сохраняются | там же |
| Восстановление снизу вверх, порциями за тик | `restore/RestoreJob.restoreSome` |
| Очередь хранится в мире (`world/<dim>/data/rupture_restore.dat`) | `restore/RuptureSavedData` |

## Конфиг
`world/serverconfig/rupture-server.toml` создаётся при первом заходе в мир. В нём время зарядки, кривая урона, радиусы, порог «истинного» урона, задержка и скорость восстановления.

## Как это устроено
- Блоки удаляются флагами `UPDATE_CLIENTS | UPDATE_KNOWN_SHAPE | UPDATE_SUPPRESS_DROPS`, без обновлений соседей. Поэтому факелы не отваливаются, песок не сыплется, вода не затекает.
- Контейнеры очищаются (`Clearable.tryClear`) до удаления, иначе `onRemove` вывалит содержимое. Полный NBT уже сохранён в снимке.
- Если за время разрыва в воронку что-то поставили, при восстановлении этот блок выбивается с дропом, так что ничего не теряется.
- Блоки из тега `rupture:rupture_immune` (по умолчанию `#minecraft:wither_immune`) и блоки с отрицательной прочностью не трогаются.
- Защита спавна учитывается через `level.mayInteract`.
